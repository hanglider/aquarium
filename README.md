# Aquarium

Консольный симулятор эволюции рыб на Go. Рыбы ищут корм, делятся и передают малькам
гены с мутацией, хищники охотятся на рыб. Никто не задаёт рыбам, какими быть: быстрые
и зоркие лучше находят корм и уходят от хищников, но тратят больше энергии — и отбор
сам находит баланс.

![Аквариум: жёлтые > — рыбы, красные @ — хищники, зелёные * — корм](https://hanglider.github.io/aquarium/aquarium.gif)

**[Живой аквариум в браузере →](https://hanglider.github.io/aquarium/)** Там же графики
эволюции: как за тысячи шагов растут средняя скорость и зрение рыб.

## Установка

Скачайте бинарник для своей системы со страницы
[последнего релиза](https://github.com/hanglider/aquarium/releases/latest)
(Linux, macOS, Windows; amd64 и arm64) или поставьте через Go 1.25+:

```
go install github.com/hanglider/aquarium/cmd/aquarium@latest
```

На macOS скачанный бинарник нужно разрешить: `xattr -d com.apple.quarantine aquarium-*`.

## Запуск

```
aquarium
```

| Клавиша       | Что делает                 |
|---------------|----------------------------|
| пробел        | пауза / продолжить         |
| `n`           | один шаг, пока на паузе    |
| `q`, `Esc`, `Ctrl+C` | выход               |

При выходе программа печатает seed и команду, которой можно повторить этот же аквариум.

## Флаги

| Флаг            | По умолчанию | Что задаёт |
|-----------------|--------------|------------|
| `-width N`      | 60           | ширина аквариума в клетках |
| `-height N`     | 20           | высота аквариума в клетках |
| `-fish N`       | 20           | число рыб в начале |
| `-predators N`  | 3            | число хищников в начале (новые всё равно иногда приплывают) |
| `-speed N`      | 10           | шагов в секунду |
| `-seed N`       | случайный    | seed: с одним seed аквариум всегда одинаковый — и в терминале, и на сайте |
| `-csv файл`     | —            | писать статистику каждого шага в CSV |
| `-steps N`      | —            | прогнать N шагов без экрана, напечатать итог и выйти |
| `-version`      | —            | показать версию |

Например, посчитать 20 000 шагов и сохранить статистику:

```
aquarium -steps 20000 -seed 1 -csv stats.csv
```

В CSV по строке на шаг: `seed, step, fish, predators, food, speed, vision, cost` —
seed, номер шага, число рыб, хищников и корма, средние скорость, зрение и расход энергии рыб.

## Как устроен мир

- **Корм** `*` появляется в случайных клетках, в среднем 3 за шаг.
- **Рыба** `>` плывёт к ближайшему корму, который видит, а от хищника — уплывает.
  Каждый шаг тратит энергию; без энергии умирает, набрав 120 — делится надвое.
- **Гены**: скорость (клеток за шаг) и зрение (радиус). Малёк получает гены родителя
  с мутацией около 10%. Расход энергии: `0.4 + 0.4·скорость² + 0.1·зрение` —
  за быстроту и зоркость приходится платить.
- **Хищник** `@` плывёт к ближайшей рыбе и съедает её. Живёт по тем же правилам, а в среднем
  раз в 50 шагов новый хищник приплывает извне — иначе хищники рано или поздно
  либо съедают всех рыб, либо вымирают сами.

## Разработка

```
go test ./...                 # тесты
go run ./cmd/aquarium         # запуск из исходников
go run ./tools/gif            # GIF для README
```

Код: `internal/sim` — симуляция (без вывода на экран), `internal/render` — отрисовка
через [tcell](https://github.com/gdamore/tcell), `internal/stats` — CSV,
`cmd/aquarium` — программа, `cmd/web` — симуляция в WebAssembly для сайта.
